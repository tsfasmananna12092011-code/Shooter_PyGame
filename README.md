# Космический шутер (Space Shooter)

Динамичная 2D-аркада на Python с использованием библиотеки **Pygame**. Игроку предстоит управлять космическим кораблем, отстреливать волны НЛО и уворачиваться от астероидов, чтобы набрать победные очки.

## Особенности игры
* **Тройной залп:** При каждом выстреле корабль выпускает сразу 3 снаряда из разных точек корпуса.
* **Механика перезарядки (перегрева):** После совершения 16 выстрелов оружие блокируется на **3 секунды**, отображая предупреждение на экране.
* **Условия победы и поражения:**
  * **Победа:** Набрать **20 очков** за сбитые НЛО.
  * **Поражение:** Пропустить **5 врагов** за нижнюю границу экрана или столкнуться с НЛО / астероидом.
* **Усложнение в процессе:** После набора **10 очков** на экране появляется гигантский астероид, от которого нужно уклоняться.
* **Игровой интерфейс (HUD):** В реальном времени отображаются счетчики сбитых врагов, пропущенных НЛО и сделанных выстрелов.

## Управление
* `←` / `→` — Перемещение корабля влево и вправо.
* `Пробел` (`Space`) — Выстрел (залп из 3 снарядов).

## Требования и установка

Для запуска игры необходим **Python 3.x** и установленная библиотека **pygame**.

1. Клонируйте репозиторий или скачайте файлы проекта:
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd <папка-с-проектом>
   ```

2. Установите библиотеку Pygame:
   ```bash
   pip install pygame
   ```

3. Запустите игру (укажите актуальное имя вашего `.py` файла):
   ```bash
   python main.py
   ```

## Структура необходимых файлов (Ассеты)
В коде используются относительные пути к изображениям. В одной директории со скриптом должна находиться папка `pictures` со следующими файлами:

```text
├── main.py
└── pictures/
    ├── galaxy.jpg      # Фоновое изображение космоса (700x500)
    ├── rocket.png      # Спрайт корабля игрока
    ├── ufo.png         # Спрайт вражеского НЛО
    ├── bullet.png      # Спрайт снаряда
    └── asteroid.png    # Спрайт астероида
```

## Архитектура кода
* `GameSprite` — базовый класс для всех спрайтов, отвечающий за загрузку, масштабирование и отрисовку объектов.
* `Player` — класс игрока с обработкой горизонтального движения и методом `fire()` для создания трех снарядов.
* `Bullet` — класс снаряда, летящего вверх и автоматически удаляющегося (`kill()`) при выходе за пределы экрана.
* `Enemy` — класс вражеских НЛО, которые двигаются вниз со случайной скоростью и возрождаются сверху при пропуске.
* `Asteroid` — класс препятствия, активирующегося при достижении 10 очков.
